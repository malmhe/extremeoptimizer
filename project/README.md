# Extreme Optimizer — Fabric мод для Minecraft 1.21.11

Жесткая оптимизация FPS с авто-настройкой под железо и встроенным entity culling.

## Возможности

- **Вкладка в Sodium Options** — отдельная страница "Extreme Optimizer" с настройками.
- **Авто-оптимизация** — мод сканирует твоё железо (ядра CPU, ОЗУ, GPU) и ставит оптимальные параметры для максимального FPS.
- **Встроенный Entity Culling** — не рендерит сущности вне экрана и далеко от игрока. Можно включать/выключать одной галкой.
- **Агрессивный culling** — ещё сильнее режет лишние рендеры.
- **Настройка целевого FPS** от 60 до 1000.
- **Сокращение частиц и облаков** для слабых ПК.

## Требования

- Minecraft 1.21.11
- Fabric Loader 0.16.9+
- Fabric API
- Sodium (mc1.21.11-0.6.13)

## Сборка

```bash
./gradlew build
```

Готовый мод будет в `build/libs/extremeoptimizer-1.0.0.jar`.

## Установка

1. Закинь `extremeoptimizer-1.0.0.jar` в папку `mods`.
2. Убедись, что Sodium тоже установлен.
3. В игре: Настройки → Video Options → Sodium Options → вкладка **Extreme Optimizer**.
4. Включи "Авто-оптимизация" — мод сам подберёт настройки под твоё железо.

## Честно про FPS

Мод реально убирает лишние рендеры и подстраивает графику под твои ядра/видеокарту. Но точное число FPS зависит от твоего железа и сцены — никто не может гарантировать конкретное значение. На слабых ПК прирост ощутимее, на мощных — скромнее.
